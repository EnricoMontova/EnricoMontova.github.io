# Como organizar um projeto no Claude para o portfólio

Sugestão baseada no que funcionou (e no que deu errado) na primeira conversa.

## 1. Criar o projeto

- **Nome:** Portfólio Enrico Montovanelli
- **Descrição:** Site pessoal com menu (xerox + terminal) e páginas de Carreira, Projetos pessoais e Hobbies.

## 2. Arquivos para colocar no conhecimento do projeto

- `README.md`
- `docs/DECISOES.md` (o padrão visual e o que foi descartado)
- `docs/CONTEUDO.md` (textos e dados do site)
- As imagens de `referencias/estetica/` que ainda guiam o visual (principalmente `09-capa-foreign-xerox.jpg`, `08-swiss-international-style.jpg` e `01-glow-4eve-photobook.jpg`)

## 3. Instruções do projeto (copiar e colar)

```
Você está me ajudando a construir meu portfólio pessoal. O padrão visual e o conteúdo estão em DECISOES.md e CONTEUDO.md: siga esses arquivos.

Como trabalhar comigo:
- Escreva em português e evite travessões nos textos.
- Mude só o que eu pedir. Não acrescente elementos, enfeites ou textos que eu não pedi.
- Mantenha os padrões que já existem (cores, fontes, quadrados, linhas finas, rótulos, rolagem). Se algo novo precisar de um padrão, use um que já existe no site.
- Se não estiver claro como eu quero, pergunte antes de fazer. Uma pergunta curta é melhor que refazer.
- Toda mudança precisa funcionar no computador e no celular. Diga o que muda em cada um.
- Antes de trocar o visual de uma tela que eu aprovei, guarde a versão atual.
- Nada de visibilidade pode depender de animação de entrada.
- Para versões de teste, crie uma tela nova ao lado e deixe a principal intacta.
- Não redesenhe logos de empresas: use os arquivos oficiais em uma cor só.
- Quando eu mandar print ou vídeo de um problema, descreva o que viu antes de corrigir.
```

## 4. Como pedir as coisas

- Um assunto por mensagem, ou uma lista numerada se forem vários.
- Para visual, mande a referência e diga qual parte dela quer usar (cor, fonte, layout, animação).
- Para problemas, mande print ou vídeo e diga se é no Fit (computador) ou no Fill (celular).
- Quando gostar de uma versão, diga "essa é a principal" para ela virar o padrão.
